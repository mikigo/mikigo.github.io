# 猪蹄汤

## 纯猪蹄汤

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 猪蹄 1 只
- 姜 3 片
- 葱 3 根
- 料酒 2 勺


### 第 2 步

- 猪蹄焯水去血水
- 锅中加入清水，放入猪蹄、姜、葱、料酒
- 大火煮开后转小火慢炖 3 小时
- 加盐调味即可


</Steps>

## 花生猪蹄汤

<Steps>
### 第 1 步

准备材料：

- 猪蹄 1 只
- 花生 1 斤
- 姜 3 片
- 葱 3 根
- 料酒 2 勺


### 第 2 步

- 猪蹄焯水去血水
- 花生洗净
- 锅中加入清水，放入猪蹄、花生、姜、葱、料酒
- 大火煮开后转小火慢炖 2.5 小时
- 加盐调味即可


</Steps>
