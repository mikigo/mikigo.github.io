# 南瓜汤

## 纯南瓜汤

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 南瓜 1 斤
- 姜 2 片
- 盐 适量


### 第 2 步

- 南瓜去皮切块
- 锅中加入清水，放入南瓜、姜
- 大火煮开后转小火煮 20 分钟
- 用搅拌机打成泥状
- 加盐调味即可


</Steps>

## 牛奶南瓜汤

<Steps>
### 第 1 步

准备材料：

- 南瓜 1 斤
- 牛奶 250ml
- 姜 2 片
- 糖 适量


### 第 2 步

- 南瓜去皮切块
- 锅中加入清水，放入南瓜、姜
- 大火煮开后转小火煮 20 分钟
- 用搅拌机打成泥状
- 加入牛奶，小火煮开
- 加糖调味即可


</Steps>
