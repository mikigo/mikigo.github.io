# 银耳汤

## 纯银耳汤

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 银耳 1 朵
- 冰糖 2 两
- 清水适量


### 第 2 步

- 银耳泡发后撕成小朵
- 锅中加入清水，放入银耳
- 大火煮开后转小火慢炖 1 小时
- 加入冰糖，煮至冰糖融化
- 关火即可


</Steps>

## 银耳雪梨汤

<Steps>
### 第 1 步

准备材料：

- 银耳 1 朵
- 雪梨 1 个
- 冰糖 2 两
- 清水适量


### 第 2 步

- 银耳泡发后撕成小朵，雪梨洗净切块
- 锅中加入清水，放入银耳、雪梨
- 大火煮开后转小火慢炖 1.5 小时
- 加入冰糖，煮至冰糖融化
- 关火即可


</Steps>
