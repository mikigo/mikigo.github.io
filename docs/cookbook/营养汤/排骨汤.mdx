# 排骨汤

## 纯排骨汤

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 猪排骨 1 斤
- 姜 2 片
- 葱 2 根
- 料酒 1 勺


### 第 2 步

- 排骨焯水去血水
- 锅中加入清水，放入排骨、姜、葱、料酒
- 大火煮开后转小火慢炖 2 小时
- 加盐调味即可


</Steps>

## 玉米排骨汤

<Steps>
### 第 1 步

准备材料：

- 猪排骨 1 斤
- 玉米 2 根
- 胡萝卜 1 根
- 姜 2 片
- 葱 2 根
- 料酒 1 勺


### 第 2 步

- 排骨焯水去血水
- 玉米切段，胡萝卜切块
- 锅中加入清水，放入排骨、玉米、胡萝卜、姜、葱、料酒
- 大火煮开后转小火慢炖 1.5 小时
- 加盐调味即可


</Steps>
