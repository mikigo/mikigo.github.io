# 羊肉汤

## 纯羊肉汤

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 羊肉 1 斤
- 姜 3 片
- 葱 3 根
- 料酒 2 勺
- 花椒 1 勺


### 第 2 步

- 羊肉切块，焯水去血水
- 锅中加入清水，放入羊肉、姜、葱、料酒、花椒
- 大火煮开后转小火慢炖 3 小时
- 加盐调味即可


</Steps>

## 山药羊肉汤

<Steps>
### 第 1 步

准备材料：

- 羊肉 1 斤
- 山药 1 根
- 姜 3 片
- 葱 3 根
- 料酒 2 勺
- 花椒 1 勺


### 第 2 步

- 羊肉切块，焯水去血水
- 山药去皮切块
- 锅中加入清水，放入羊肉、山药、姜、葱、料酒、花椒
- 大火煮开后转小火慢炖 2.5 小时
- 加盐调味即可


</Steps>
