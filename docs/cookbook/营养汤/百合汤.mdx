# 百合汤

## 纯百合汤

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 百合 1 斤
- 冰糖 2 两
- 清水适量


### 第 2 步

- 百合洗净
- 锅中加入清水，放入百合
- 大火煮开后转小火煮 20 分钟
- 加入冰糖，煮至冰糖融化
- 关火即可


</Steps>

## 百合莲子汤

<Steps>
### 第 1 步

准备材料：

- 百合 1 斤
- 莲子 1 两
- 冰糖 2 两
- 清水适量


### 第 2 步

- 百合洗净，莲子洗净去芯
- 锅中加入清水，放入百合、莲子
- 大火煮开后转小火慢炖 1 小时
- 加入冰糖，煮至冰糖融化
- 关火即可


</Steps>
