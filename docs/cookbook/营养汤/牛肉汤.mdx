# 牛肉汤

## 纯牛肉汤

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 牛肉 1 斤
- 姜 3 片
- 葱 3 根
- 料酒 2 勺


### 第 2 步

- 牛肉切块，焯水去血水
- 锅中加入清水，放入牛肉、姜、葱、料酒
- 大火煮开后转小火慢炖 3 小时
- 加盐调味即可


</Steps>

## 萝卜牛肉汤

<Steps>
### 第 1 步

准备材料：

- 牛肉 1 斤
- 白萝卜 1 个
- 姜 3 片
- 葱 3 根
- 料酒 2 勺


### 第 2 步

- 牛肉切块，焯水去血水
- 白萝卜切块
- 锅中加入清水，放入牛肉、白萝卜、姜、葱、料酒
- 大火煮开后转小火慢炖 2.5 小时
- 加盐调味即可


</Steps>
