# 菠菜汤

## 纯菠菜汤

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 菠菜 1 斤
- 姜 2 片
- 葱 2 根
- 盐 适量


### 第 2 步

- 菠菜洗净切段
- 锅中加入清水，放入姜、葱
- 大火煮开后加入菠菜
- 煮 2-3 分钟至菠菜熟透
- 加盐调味即可


</Steps>

## 菠菜蛋花汤

<Steps>
### 第 1 步

准备材料：

- 菠菜 1 斤
- 鸡蛋 2 个
- 姜 2 片
- 葱 2 根
- 盐 适量


### 第 2 步

- 菠菜洗净切段，鸡蛋打散备用
- 锅中加入清水，放入姜、葱
- 大火煮开后加入菠菜
- 煮 2-3 分钟至菠菜熟透
- 淋入蛋液，搅拌均匀
- 加盐调味即可


</Steps>
