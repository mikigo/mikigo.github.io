# 鲫鱼汤

## 纯鲫鱼汤

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 鲫鱼 1 条（约 1 斤）
- 姜 3 片
- 葱 3 根
- 料酒 1 勺


### 第 2 步

- 鲫鱼处理干净，两面煎至金黄
- 锅中加入清水，放入鲫鱼、姜、葱、料酒
- 大火煮开后转小火慢炖 1 小时
- 加盐调味即可


</Steps>

## 豆腐鲫鱼汤

<Steps>
### 第 1 步

准备材料：

- 鲫鱼 1 条（约 1 斤）
- 嫩豆腐 1 盒
- 姜 3 片
- 葱 3 根
- 料酒 1 勺


### 第 2 步

- 鲫鱼处理干净，两面煎至金黄
- 豆腐切块
- 锅中加入清水，放入鲫鱼、豆腐、姜、葱、料酒
- 大火煮开后转小火慢炖 40 分钟
- 加盐调味即可


</Steps>
