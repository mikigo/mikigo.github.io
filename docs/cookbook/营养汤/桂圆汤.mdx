# 桂圆汤

## 纯桂圆汤

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 桂圆 1 斤
- 冰糖 2 两
- 清水适量


### 第 2 步

- 桂圆洗净
- 锅中加入清水，放入桂圆
- 大火煮开后转小火煮 20 分钟
- 加入冰糖，煮至冰糖融化
- 关火即可


</Steps>

## 桂圆红枣汤

<Steps>
### 第 1 步

准备材料：

- 桂圆 1 斤
- 红枣 1 两
- 冰糖 2 两
- 清水适量


### 第 2 步

- 桂圆洗净，红枣洗净去核
- 锅中加入清水，放入桂圆、红枣
- 大火煮开后转小火慢炖 1 小时
- 加入冰糖，煮至冰糖融化
- 关火即可


</Steps>
