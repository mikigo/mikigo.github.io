# 开水白菜

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 大白菜心 4 颗
- 老母鸡 1 只（约 2 斤）
- 猪排骨 1 斤
- 火腿 2 两
- 姜 2 片
- 葱 2 根
- 料酒 2 勺
- 盐 适量


### 第 2 步

- 老母鸡、猪排骨焯水去血水
- 锅中加入清水，放入老母鸡、猪排骨、火腿、姜、葱、料酒
- 大火煮开后转小火慢炖 4 小时，期间撇去浮沫

### 第 3 步

- 将炖好的汤用纱布过滤 3 次，直至汤清澈透明
- 白菜心洗净，放入沸水中焯水 10 秒，捞出过冷水

### 第 4 步

- 将白菜心放入碗中，加入过滤好的清汤
- 上笼蒸 10 分钟
- 取出后加盐调味即可

</Steps>
