# 川北凉粉

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 绿豆淀粉 1 斤
- 清水 5 斤
- 红油辣椒 3 勺
- 花椒粉 1 勺
- 生抽 2 勺
- 香醋 2 勺
- 白糖 1 勺
- 盐 适量
- 蒜末 1 勺
- 葱花 适量
- 芝麻 1 勺


### 第 2 步

- 将绿豆淀粉和 1 斤清水混合成淀粉浆
- 锅中加入 4 斤清水，大火煮开
- 转小火，将淀粉浆缓慢倒入锅中，边倒边搅拌
- 搅拌至淀粉浆变透明浓稠，关火

### 第 3 步

- 将煮好的淀粉浆倒入容器中，自然冷却
- 冷却后放入冰箱冷藏 2 小时，至完全凝固
- 取出后切成条状

### 第 4 步

- 调制调味汁：将红油辣椒、花椒粉、生抽、香醋、白糖、盐、蒜末混合均匀
- 将切好的凉粉放入碗中，淋上调味汁
- 撒上葱花和芝麻即可

</Steps>
