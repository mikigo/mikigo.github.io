# 鱼香肉丝

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 猪里脊肉 1 斤
- 青椒 2 个
- 红椒 2 个
- 木耳 1 两
- 姜 1 片
- 蒜 2 瓣
- 葱 2 根
- 料酒 1 勺
- 生抽 2 勺
- 老抽 1 勺
- 白糖 1 勺
- 醋 1 勺
- 淀粉 2 勺
- 盐 适量


### 第 2 步

- 猪里脊肉洗净切丝，用料酒、生抽、淀粉腌制 20 分钟
- 青椒、红椒切丝，木耳泡发后切丝
- 姜、蒜切末，葱切段

### 第 3 步

- 锅中加油，放入腌制好的肉丝翻炒至变色
- 加入姜蒜末炒香
- 加入青椒、红椒、木耳翻炒均匀
- 加入老抽、白糖、醋调味

### 第 4 步

- 翻炒均匀后，放入葱段
- 水淀粉勾芡即可出锅

</Steps>
