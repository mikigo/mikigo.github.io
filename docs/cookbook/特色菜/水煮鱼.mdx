# 水煮鱼

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 草鱼 1 条（约 3 斤）
- 豆芽 1 斤
- 干辣椒 2 两
- 花椒 2 勺
- 姜 3 片
- 蒜 5 瓣
- 葱 3 根
- 料酒 2 勺
- 生抽 2 勺
- 盐 适量
- 淀粉 2 勺


### 第 2 步

- 草鱼洗净，片成鱼片
- 用料酒、生抽、盐、淀粉腌制 20 分钟
- 豆芽洗净，放入沸水中焯水至断生，捞出铺在碗底

### 第 3 步

- 锅中加油，放入姜、蒜、葱炒香
- 加入适量清水，大火煮开
- 放入腌制好的鱼片，煮至变色
- 捞出鱼片铺在豆芽上
- 锅中的汤汁继续煮开，加入盐调味，淋在鱼片上

### 第 4 步

- 锅中加入适量油，放入干辣椒、花椒爆香
- 将爆香的辣椒和花椒淋在鱼片上即可

</Steps>
