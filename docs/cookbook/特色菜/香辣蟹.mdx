# 香辣蟹

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 大闸蟹 4 只（约 2 斤）
- 干辣椒 1 两
- 花椒 1 勺
- 姜 3 片
- 蒜 5 瓣
- 葱 3 根
- 料酒 2 勺
- 生抽 2 勺
- 老抽 1 勺
- 白糖 1 勺
- 盐 适量


### 第 2 步

- 大闸蟹洗净，切成小块
- 放入锅中焯水去血水
- 捞出备用

### 第 3 步

- 锅中加油，放入姜、蒜、葱炒香
- 放入干辣椒、花椒爆香
- 放入大闸蟹翻炒均匀
- 加入料酒、生抽、老抽、白糖调味
- 加入适量清水，大火煮开后转小火炖 15 分钟

### 第 4 步

- 至大闸蟹熟透入味后，加入盐调味
- 翻炒均匀即可出锅

</Steps>
