# 东坡肘子

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 猪肘子 1 个（约 3 斤）
- 姜 3 片
- 葱 3 根
- 料酒 3 勺
- 生抽 3 勺
- 老抽 1 勺
- 白糖 1 勺
- 八角 2 个
- 桂皮 1 小块
- 香叶 2 片
- 盐 适量


### 第 2 步

- 猪肘子洗净，放入锅中焯水去血水
- 捞出后在表面划几刀，方便入味

### 第 3 步

- 锅中加入清水，放入猪肘子、姜、葱、料酒、八角、桂皮、香叶
- 大火煮开后转小火炖 3 小时，至猪肘子熟透
- 加入生抽、老抽、白糖、盐调味
- 继续炖 30 分钟，至汤汁浓稠

### 第 4 步

- 将猪肘子捞出，放入盘中
- 淋上锅中的汤汁即可

</Steps>
