# 麻辣香锅

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 虾 1 斤
- 鸡翅中 1 斤
- 土豆 2 个
- 藕 1 节
- 青椒 2 个
- 红椒 2 个
- 洋葱 1 个
- 干辣椒 1 两
- 花椒 1 勺
- 姜 3 片
- 蒜 5 瓣
- 葱 3 根
- 料酒 2 勺
- 生抽 2 勺
- 老抽 1 勺
- 白糖 1 勺
- 盐 适量


### 第 2 步

- 虾洗净，去虾线
- 鸡翅中洗净，焯水去血水
- 土豆、藕切片，青椒、红椒切块，洋葱切丝

### 第 3 步

- 锅中加油，放入虾炸至金黄，捞出备用
- 锅中加油，放入鸡翅中炸至金黄，捞出备用
- 锅中加油，放入土豆、藕片炸至金黄，捞出备用

### 第 4 步

- 锅中留底油，放入姜、蒜、葱炒香
- 放入干辣椒、花椒爆香
- 放入洋葱、青椒、红椒翻炒均匀
- 放入炸好的虾、鸡翅中、土豆、藕片翻炒均匀
- 加入料酒、生抽、老抽、白糖、盐调味
- 翻炒均匀即可出锅

</Steps>
