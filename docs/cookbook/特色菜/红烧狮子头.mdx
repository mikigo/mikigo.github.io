# 红烧狮子头

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 猪五花肉 2 斤
- 荸荠 4 个
- 鸡蛋 2 个
- 姜 1 片
- 葱 2 根
- 料酒 2 勺
- 生抽 2 勺
- 老抽 1 勺
- 白糖 1 勺
- 淀粉 3 勺
- 盐 适量
- 胡椒粉 1 勺


### 第 2 步

- 猪五花肉洗净，剁碎成肉糜
- 荸荠洗净去皮，剁碎
- 姜、葱切末
- 将肉糜、荸荠末、姜葱末、鸡蛋、料酒、生抽、淀粉、盐、胡椒粉混合均匀，顺时针搅拌上劲

### 第 3 步

- 锅中加油，烧至 6 成热
- 将肉糜揉成拳头大小的狮子头，放入锅中炸至表面金黄
- 捞出备用

### 第 4 步

- 锅中留底油，加入姜片、葱段炒香
- 加入适量清水，放入炸好的狮子头
- 加入料酒、老抽、白糖调味
- 大火煮开后转小火炖 1.5 小时
- 至狮子头熟透入味即可

</Steps>
