# 糖醋排骨

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 猪排骨 2 斤
- 姜 2 片
- 葱 2 根
- 料酒 2 勺
- 生抽 2 勺
- 老抽 1 勺
- 白糖 2 勺
- 醋 2 勺
- 淀粉 1 勺
- 盐 适量


### 第 2 步

- 猪排骨洗净，切成小块
- 放入锅中焯水去血水
- 捞出备用

### 第 3 步

- 锅中加油，放入姜、葱炒香
- 放入排骨翻炒均匀
- 加入料酒、生抽、老抽调味
- 加入适量清水，大火煮开后转小火炖 1 小时

### 第 4 步

- 至排骨熟透后，加入白糖、醋调味
- 水淀粉勾芡，至汤汁浓稠即可出锅

</Steps>
