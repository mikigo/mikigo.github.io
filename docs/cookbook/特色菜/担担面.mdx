# 担担面

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 面条 1 斤
- 猪里脊肉 1 斤
- 芽菜 2 两
- 姜 1 片
- 蒜 2 瓣
- 葱 2 根
- 料酒 1 勺
- 生抽 2 勺
- 红油辣椒 3 勺
- 花椒粉 1 勺
- 盐 适量
- 芝麻 1 勺


### 第 2 步

- 猪里脊肉洗净，剁碎成肉糜
- 姜、蒜切末，葱切段

### 第 3 步

- 锅中加油，放入肉糜翻炒至变色
- 加入姜蒜末炒香
- 加入芽菜翻炒均匀
- 加入料酒、生抽调味
- 翻炒均匀后盛出备用

### 第 4 步

- 锅中加入清水，大火煮开
- 放入面条，煮至熟透
- 调制调味汁：将红油辣椒、花椒粉、盐、芝麻混合均匀
- 将煮好的面条捞出，放入碗中，淋上调味汁，再铺上炒好的肉糜即可

</Steps>
