# 回锅肉

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 五花肉 2 斤
- 青椒 2 个
- 蒜苗 2 根
- 豆瓣酱 2 勺
- 甜面酱 1 勺
- 姜 1 片
- 蒜 2 瓣
- 料酒 1 勺
- 生抽 1 勺
- 盐 适量


### 第 2 步

- 五花肉洗净，放入锅中焯水至断生
- 捞出放凉后切片
- 青椒切块，蒜苗切段
- 姜、蒜切末

### 第 3 步

- 锅中加油，放入五花肉片炒至出油
- 加入豆瓣酱、甜面酱、姜蒜末炒香
- 加入料酒、生抽调味

### 第 4 步

- 放入青椒、蒜苗翻炒至断生
- 翻炒均匀后即可出锅

</Steps>
