# 口水鸡

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 三黄鸡 1 只（约 2 斤）
- 姜 3 片
- 葱 3 根
- 料酒 2 勺
- 红油辣椒 3 勺
- 花椒粉 1 勺
- 生抽 2 勺
- 香醋 1 勺
- 白糖 1 勺
- 蒜末 1 勺
- 芝麻 1 勺
- 香菜 适量


### 第 2 步

- 三黄鸡洗净，放入锅中
- 加入清水、姜、葱、料酒
- 大火煮开后转小火煮 20 分钟，至鸡肉熟透
- 捞出后放入冰水中浸泡 10 分钟，保持鸡肉鲜嫩

### 第 3 步

- 将冷却后的鸡肉切成小块，放入碗中
- 调制调味汁：将红油辣椒、花椒粉、生抽、香醋、白糖、蒜末混合均匀

### 第 4 步

- 将调味汁淋在鸡肉上
- 撒上芝麻和香菜即可

</Steps>
