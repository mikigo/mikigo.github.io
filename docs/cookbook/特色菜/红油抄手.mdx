# 红油抄手

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 猪里脊肉 1 斤
- 抄手皮 50 张
- 姜 1 片
- 葱 2 根
- 料酒 1 勺
- 生抽 2 勺
- 盐 适量
- 胡椒粉 1 勺
- 红油辣椒 3 勺
- 花椒粉 1 勺
- 醋 1 勺
- 芝麻 1 勺


### 第 2 步

- 猪里脊肉洗净，剁碎成肉糜
- 姜、葱切末
- 将肉糜、姜葱末、料酒、生抽、盐、胡椒粉混合均匀，顺时针搅拌上劲

### 第 3 步

- 取一张抄手皮，放入适量馅料
- 包成抄手形状
- 重复操作，直到包完所有抄手皮

### 第 4 步

- 锅中加入清水，大火煮开
- 放入抄手，煮至浮起后再煮 2 分钟
- 调制调味汁：将红油辣椒、花椒粉、醋、芝麻混合均匀
- 将煮好的抄手捞出，放入碗中，淋上调味汁即可

</Steps>
