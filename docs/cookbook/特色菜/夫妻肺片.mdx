# 夫妻肺片

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 牛心、牛肺、牛舌、牛肚 各 半斤
- 卤料包：八角、桂皮、香叶、草果、丁香、花椒
- 姜 2 片
- 葱 2 根
- 料酒 2 勺
- 红油辣椒 3 勺
- 花椒粉 1 勺
- 生抽 2 勺
- 香醋 1 勺
- 白糖 1 勺
- 蒜末 1 勺
- 芝麻 1 勺
- 香菜 适量


### 第 2 步

- 将牛心、牛肺、牛舌、牛肚洗净，放入锅中焯水去血水
- 锅中加入清水，放入焯水后的牛杂、卤料包、姜、葱、料酒
- 大火煮开后转小火卤制 1.5 小时，至牛杂熟透

### 第 3 步

- 将卤好的牛杂捞出，放凉后切成薄片
- 调制调味汁：将红油辣椒、花椒粉、生抽、香醋、白糖、蒜末混合均匀

### 第 4 步

- 将切好的牛杂放入碗中，淋上调味汁
- 撒上芝麻和香菜即可

</Steps>
