# 干煸四季豆

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 四季豆 2 斤
- 猪肉末 1 斤
- 干辣椒 1 两
- 花椒 1 勺
- 姜 1 片
- 蒜 2 瓣
- 葱 2 根
- 料酒 1 勺
- 生抽 2 勺
- 盐 适量


### 第 2 步

- 四季豆洗净，切成小段
- 放入锅中焯水至断生，捞出沥干水分

### 第 3 步

- 锅中加油，放入四季豆炸至表面金黄，捞出备用
- 锅中留底油，放入猪肉末翻炒至变色
- 加入姜蒜末炒香
- 放入干辣椒、花椒爆香

### 第 4 步

- 放入炸好的四季豆翻炒均匀
- 加入料酒、生抽、盐调味
- 翻炒均匀后，放入葱段即可出锅

</Steps>
