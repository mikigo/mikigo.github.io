# 泡椒凤爪

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 凤爪 2 斤
- 泡椒 1 瓶
- 姜 2 片
- 葱 2 根
- 料酒 2 勺
- 盐 适量
- 花椒 1 勺


### 第 2 步

- 凤爪洗净，剪去指甲
- 放入锅中焯水去血水，加入姜、葱、料酒
- 捞出后用冷水冲洗，沥干水分

### 第 3 步

- 将凤爪切成小块
- 放入容器中，加入泡椒、泡椒水、花椒、盐
- 搅拌均匀

### 第 4 步

- 密封容器，放入冰箱冷藏 24 小时
- 至凤爪入味即可食用

</Steps>
