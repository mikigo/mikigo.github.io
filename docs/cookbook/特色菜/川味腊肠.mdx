# 川味腊肠

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 猪后腿肉 5 斤
- 猪小肠衣 1 套
- 盐 2 勺
- 花椒粉 2 勺
- 辣椒粉 2 勺
- 白糖 1 勺
- 白酒 2 勺


### 第 2 步

- 猪后腿肉洗净，切成小块
- 用绞肉机绞成肉糜
- 加入盐、花椒粉、辣椒粉、白糖、白酒，搅拌均匀

### 第 3 步

- 将猪小肠衣洗净，套在灌肠器上
- 将搅拌好的肉糜灌入肠衣中
- 每隔 10 厘米用棉线扎成一节

### 第 4 步

- 将灌好的腊肠挂在通风处晾干
- 晾干后放入冰箱冷藏保存
- 食用时蒸熟即可

</Steps>
