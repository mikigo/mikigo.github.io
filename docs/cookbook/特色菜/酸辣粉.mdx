# 酸辣粉

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 红薯粉 1 斤
- 花生 1 斤
- 黄豆 1 斤
- 香菜 适量
- 葱花 适量
- 红油辣椒 3 勺
- 花椒粉 1 勺
- 生抽 2 勺
- 香醋 2 勺
- 白糖 1 勺
- 盐 适量


### 第 2 步

- 花生放入锅中炸至金黄，捞出备用
- 黄豆放入锅中炸至金黄，捞出备用

### 第 3 步

- 红薯粉放入沸水中煮至熟透，捞出备用

### 第 4 步

- 调制调味汁：将红油辣椒、花椒粉、生抽、香醋、白糖、盐混合均匀
- 将煮好的红薯粉放入碗中，淋上调味汁
- 撒上花生、黄豆、香菜和葱花即可

</Steps>
