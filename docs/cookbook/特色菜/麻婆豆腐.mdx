# 麻婆豆腐

import { Steps } from '@rspress/core/theme';

<Steps>
### 第 1 步

准备材料：

- 嫩豆腐 2 盒
- 牛肉末 1 斤
- 豆瓣酱 2 勺
- 辣椒面 1 勺
- 花椒粉 1 勺
- 姜 1 片
- 蒜 2 瓣
- 葱 2 根
- 料酒 1 勺
- 生抽 2 勺
- 白糖 1 勺
- 淀粉 1 勺
- 盐 适量


### 第 2 步

- 豆腐切块，放入沸水中焯水 2 分钟，捞出备用
- 姜、蒜切末，葱切段

### 第 3 步

- 锅中加油，放入牛肉末炒至变色
- 加入豆瓣酱、辣椒面、姜蒜末炒香
- 加入料酒、生抽、白糖调味
- 加入适量清水煮开

### 第 4 步

- 放入焯水后的豆腐，轻轻翻炒
- 水淀粉勾芡
- 撒上花椒粉和葱段即可

</Steps>
