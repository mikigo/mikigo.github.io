# the Caddy web server - YYDS

**新域名**

最近我之前的域名 zeng-yi.com 快要到期了，挺纠结是续期还是重新注册一个新的域名。想了一段时间之后还是重新买了一个 mikigo.site，毕竟 mikigo 这个名字还是挺有辨识度的。

mikigo.site 这个域名在注册使用的时候还遇到一系列烦人的问题：

- 被注册局标记锁定serverHold

- 浏览器标记为恶意网站

但问题是我新买的什么都没做，为什么会被标记为恶意网站呢？经过一番调查，是因为这个域名之前被人注册过，可能是被用来做过一些不当的事情。

我只能挨个申请解除锁定，联系注册商和浏览器厂商，经过一段时间的沟通，终于把这些问题都解决了。

**Caddy**

在重新注册域名之后，我就开始考虑网站的部署问题。之前一直使用的是 Nginx 作为服务器，每次配置 SSL 都要费力，每隔一段时间就要更新证书，damn~~ 😵

之前知道 Caddy 这个 Web 服务器挺不错的，支持自动 HTTPS 配置，而且配置文件也相对简单易懂，但是一直没有机会尝试。

于是我决定尝试使用 Caddy 来部署我的网站。

果断把 Nginx 卸载掉，安装 Caddy。

Caddy 的配置文件使用的是 Caddyfile 格式，语法非常简洁明了。只需要几行代码就可以完成 SSL 的配置和反向代理的设置。

以下是我使用 Caddyfile 配置的示例：

```caddyfile

mikigo.site {

	root * /var/www/mikigo.site

	file_server
}
```

就两行配置就可以完成网站的部署。Caddy 会自动处理 HTTPS 的证书申请和续期，极大地简化了部署流程。

再也不用担心证书过期的问题了，YYDS！🖖🖖🖖
