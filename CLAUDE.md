## Architecture

This is a Chinese-language personal site built with [Rspress](https://rspress.dev/) (v2), a React-based static site generator. Content is authored in MDX/Markdown and built to static HTML deployed via GitHub Pages.

### Directory layout

- **`docs/`** — All page content. Rspress treats this as the content root (`root: 'docs'` in config).
  - `index.md` — Home page (`pageType: home` with hero and features grid)
  - `_nav.json` — Top navigation bar items (首页, 编程, 技术文档, 博客, 菜谱)
  - `blog/` — Blog posts keyed by date (e.g., `2026-05-21.mdx`), plus a `2024/` subdirectory for older posts. Each has frontmatter with `date`, `authors`, `description`, `sidebar: false`, `pageType: doc-wide`.
  - `program/` — Programming articles
  - `tech_doc/` — Technical documentation articles
  - `cookbook/` — Recipe collection
  - `public/` — Static assets (favicon, logo, etc.)
- **`theme/`** — Custom theme extending Rspress defaults.
  - `index.tsx` — Layout override adding "我创建的开源项目" header before features on the home page and a copyright disclaimer after doc content
  - `index.css` — Minor layout fix to reduce sidebar placeholder width on large screens
  - `var.css` — CSS custom properties for brand colors (green palette) and code highlighting (GitHub-dark theme), plus overrides for logo shadow, nav styling, heading sizes
- **`components/`** — Custom React components used in MDX pages.
  - `Blog/index.tsx` — `BlogList` component and `useBlogPages` hook that filter, sort, and render blog posts from route data
  - `Blog/BlogAvatar.tsx` — Author avatar component for blog posts
- **`scripts/`** — Python utility scripts for content management:
  - `update_blog_frontmatter.py` — Batch-updates frontmatter for blog files in `docs/blog/2024/`
  - `insert_badge.py` — Inserts Rspress `<Badge>` component after first-level headings in tech_doc MDX files
  - `translate_md_by_openrouter.py` — Translates Markdown content via OpenRouter API
  - `request_paddleocr_server.py` — OCR helper script
- **`doc_build/`** — Build output. This is the directory deployed to GitHub Pages. Never edit files here directly — they are regenerated by `pnpm build`.
- **`rspress.config.ts`** — Rspress configuration. Key settings: `lang: 'zh'`, `cleanUrls: true`, `route.exclude: ['components/**']`, sitemap plugin with `https://mikigo.site`.

### Content authoring

- Content is in MDX (`.mdx`) or Markdown (`.md`). MDX allows embedding React components directly in pages.
- Frontmatter fields used: `date`, `authors` (array), `description`, `sidebar`, `pageType` (e.g., `doc-wide` for full-width), `title`.
- Blog posts go in `docs/blog/` with filenames like `YYYY-MM-DD.mdx`. Older posts (2024) are in `docs/blog/2024/` with descriptive filenames.
- The `_meta.json` files in subdirectories control sidebar ordering within that section.

### CI/CD

- **Deploy** (`.github/workflows/deploy.yml`): On push to `main`, installs deps with pnpm, builds, and deploys `doc_build/` to GitHub Pages via `peaceiris/actions-gh-pages`.
- **Sync to Gitee** (`.github/workflows/sync-to-gitee.yml`): After deploy completes, mirrors the repo to Gitee.

### Tech stack

- Rspress v2 (static site generator, React-based)
- pnpm 10 as package manager
- Node 22
- TypeScript with `moduleResolution: "bundler"`
- Shiki for syntax highlighting (dark theme)
- `@rspress/plugin-sitemap` for sitemap generation
